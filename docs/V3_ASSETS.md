# V3 frame/arena production notes

The renderer now extracts exact cells instead of reading a 270-pixel action row from a 256-pixel source row. It labels alpha-connected components to retain the fighter’s main body and its one-pixel edge fringe while rejecting disconnected neighboring-cell limbs. Detached magic particles are rendered by separate gameplay effect/projectile objects rather than retained as atlas debris.

All runtime cells are 256×256. Base sources remain 192×256; signatures remain 256×256. Frames normally place the feet anchor at `(128,244)`. Wide/tall poses receive an explicit offset and pivot so their full connected body fits without clipping. Mirroring uses the complemented horizontal pivot. The body stays anchored in world coordinates while the collision system continues to use independent deterministic hit/hurt/push boxes. Per-frame metadata is attached to the Phaser texture and the training inspector exposes the resulting frame/anchor and collision overlays.

The four original fighters retain 48 base/action/walk poses and 24 signature poses. Frost, Rob Father and Santa have separate 32-pose base sheets and 24 signature poses each. The new bosses share artwork between their boss and standard playable profiles, while balance/armour/phase rules differ. Rob Father is an original moustached festive kingpin in a burgundy fur-lined coat; Santa is an original white-bearded red-and-white winter champion. The new Collection Hall and North Pole throne scenes were generated specifically for this project. No commercial character/film actor/game assets are used.

`npm run assets:prepare` reproduces runtime WebPs from the preserved PNG masters. Normal build/CI uses the committed runtime assets directly. Source/runtimes use lossless conversion; visual extraction and animation metadata are separate renderer operations, not collision shape generation.

The repair removes runtime row overflow and disconnected-cell bleed; it cannot invent an authored limb already truncated in an imperfect source drawing. Generated anatomy, all per-pose contact endpoints, physical foot/world-speed alignment, directional jump/dash extensions and longer victory choreography still need art direction. Boss locomotion has four source stride poses; the original four fighters retain eight. These are explicit production gates, not finished claims based on frame counts.

Scenery uses existing illustrated background/midground/ground bands plus independent smoke, reflections, lighting, mist, gifts, snow, sleigh and boss-phase glow. Fully hand-separated foreground objects and more elaborate environmental animation remain open. Camera framing expands safely around separation/jumps, contracts smoothly, and uses reduced-effects settings. The fixed DOM HUD and touch controls are independent of world zoom.
